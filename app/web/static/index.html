    분석 방법론

    1. Planner — 질문을 하위 항목으로 나누고 필요한 데이터 소스를 선택
    2. Retriever — OpenDART · ECOS · KOSIS · 기업 IR 원문 수집
    3. Parser — 제목·발행일·기준기간·단위·원문 구절 추출
    4. Claim Extractor — 핵심 주장과 수치 구조화
    5. Evidence Checker — 지지 근거 / 반대 근거 / 상충 / 불확실성 분리
    6. Outlook — 근거 방향 가중치로 상승·하락 확률 산출
    7. Report — 출처 링크 포함 브리핑 생성

    LLM(NVIDIA NIM)은 문장 정리와 방향 분류에만 사용합니다. 모든 수치와 인용은 원문 대조를 통과해야 결과에 포함됩니다.
